Console Icons & Folder Organization Guide
How Console Icon Folders Work:
Per-Console Subfolders on Disk:

All icons in ROMcat are organized into dedicated console folders inside static/icons/. Each folder represents a console (e.g. nes/, snes/, ps3/, switch/, custom/).

  • Automatic Category Tabs: Creating a new folder inside static/icons/ automatically creates a matching tab in the icon picker!
  • Multiple Icons per Console: You can place multiple icons inside any console folder (for example: official logos, controllers, console artwork). Clicking that console's tab displays all icons in that folder.
  • Supported Formats: .png, .svg, .webp, .ico, .jpg, .jpeg.
Uploading & Adding Icons:
Category-Aware Uploads:
  • Selected Category: When you select a console tab (e.g. PS3) and upload an icon, it is automatically saved directly into that console's folder (static/icons/ps3/).
  • General / All: If All is selected, uploaded images are placed in static/icons/custom/.
  • Tab Row Upload: Clicking Upload on an individual tab row under "Customize Console Tab Icons" automatically saves the icon into that console's folder.
  • File Manager Access: Click 📁 Open Icons Folder to open static/icons/ directly in your system file manager (Nautilus, Nemo, Dolphin) and drag & drop files or create folders freely.
  • New Folders: Click + New Folder to create a new console directory right from the browser.
Manufacturer Tab Grouping:
Organized by Manufacturer:

Tabs are ordered by manufacturer family: Nintendo → PlayStation → Xbox → Sega → Atari → Commodore → Retro → Custom.

Tab Icon Auto-Matching:
Automatic Discovery:

When "Display Icons on Console Tabs" is toggled ON, ROMcat automatically checks if an icon exists in a matching console folder. You can always override any specific tab using the "Customize Console Tab Icons" list below.

All Auto

Tab icons are matched automatically by default. Click any console tab to change its icon.

Selecting an icon below immediately sets it as your browser tab's Favicon and catalog Header Icon.

💡 Clicking an icon or uploading/pasting a path sets it as your browser favicon and header icon.

Cover Art & Smart Scraper Guide
Smart Scraper Intelligence:
Automatic Multi-Pass Search & Portrait Filtering

When you click Fetch Covers (or the in-card "Find cover" picker), ROMcat applies intelligent multi-pass matching before querying SteamGridDB:

  • Noisy Tag Stripping: Automatically strips dump tags ([!], (USA), (Rev 1)), multi-disc labels ((Disc 1)), and format indicators (.nkit).
  • Subtitle & Numeral Fallbacks: Tries exact titles, subtitle splits (e.g. Zelda - Ocarina of Time → Ocarina of Time), and Roman numeral variations (II ↔ 2).
  • Authentic Box Art Dimensions: Prioritizes high-resolution vertical portrait covers (600×900, 342×482, 660×930).
  • Curated Quality: Excludes joke/meme grids (humor=false) and adult artwork (nsfw=false).
Folder Location for Custom Box Art:
Manual Cover Placement:

Place custom image files directly into the static/covers/ directory in your ROMcat installation folder.

Cover Image Naming Formula:
Format: <system_id>_<rom_filename_without_extension>.jpg

Spaces, parentheses, brackets, dots, and special characters in the ROM filename are replaced with underscores (_).

Naming Examples:
NES:
ROM: Super Mario Bros (USA).nes
→ Cover: nes_Super_Mario_Bros__USA_.jpg
SNES:
ROM: Chrono Trigger [!].sfc
→ Cover: snes_Chrono_Trigger____.jpg
Nintendo 64:
ROM: The Legend of Zelda - Ocarina of Time (USA).z64
→ Cover: n64_The_Legend_of_Zelda_-_Ocarina_of_Time__USA_.jpg
GameCube:
ROM: Super Smash Bros Melee.iso
→ Cover: gamecube_Super_Smash_Bros_Melee.jpg
Switch:
ROM: Super Mario Odyssey.nsp
→ Cover: Switch_Super_Mario_Odyssey.jpg
Image Specifications & Tips:
  • Supported Formats: .jpg, .jpeg, .png, .webp
  • Recommended Aspect Ratio: Standard vertical box art ratio 3:4 (e.g. 300 × 400 or 600 × 800 pixels).
  • Instant Refresh: After copying images to static/covers/, click Rescan below to instantly update the catalog.
  • In-Catalog Search: Click Find cover on any game card missing art to browse and select from live SteamGridDB choices.

Consoles & Commands Configuration Guide
System Identifier (ID) — When is it needed?

You can leave this box empty. When you fill in the Display Name (such as Nintendo 64), ROMcat automatically creates a safe internal ID for you behind the scenes.

Only type in this box if:

  • Your Display Name contains special characters, slashes, or symbols (e.g. Game Boy / Color or PC Engine & TG-16) and you want a clean internal key like gbc or pce.
  • You specifically want a custom short nickname (like n64 instead of nintendo64).

The Emulator Launch Command is the exact shell command used to start the emulator with your selected game.

Key Token: {rom}

ROMcat automatically replaces {rom} with the full, shell-quoted path to the selected ROM file on disk (e.g. "/home/user/ROMs/NES/Mario.nes").

Common Flatpak Emulator Commands:
NES: flatpak run ca._0ldsk00l.Nestopia {rom}
SNES: flatpak run com.snes9x.Snes9x {rom}
Nintendo 64: flatpak run io.github.gopher64.gopher64 {rom}
GameCube / Wii: flatpak run org.DolphinEmu.dolphin-emu {rom}
Wii U: flatpak run info.cemu.Cemu -g {rom}
Switch: flatpak run org.yuzu_emu.yuzu -g {rom}
PlayStation 1: flatpak run org.duckstation.DuckStation {rom}
PlayStation 2: flatpak run net.pcsx2.PCSX2 {rom}
PlayStation 3: flatpak run net.rpcs3.RPCS3 {rom}
Native Binaries, RetroArch & Windows:
RetroArch (Core): retroarch -L /path/to/core_libretro.so {rom}
AppImage / Binary: /home/user/Applications/emulator.AppImage {rom}
Windows (.exe): "C:\Emulators\Dolphin\Dolphin.exe" -b -e {rom}
Eden / Standalone: /home/user/Applications/Eden -g {rom}
