How to Format Emulator Launch Commands

The Emulator Launch Command is the exact shell command used to start the emulator with your selected game.

Key Token: {rom}

ROM Cat automatically replaces {rom} with the full, shell-quoted path to the selected ROM file on disk (e.g. "/home/user/ROMs/NES/Mario.nes").

Common Flatpak Emulator Commands:
NES: flatpak run ca._0ldsk00l.Nestopia {rom}
SNES: flatpak run com.snes9x.Snes9x {rom}
Nintendo 64: flatpak run io.github.gopher64.gopher64 {rom}
GameCube / Wii: flatpak run org.DolphinEmu.dolphin-emu {rom}
Wii U: flatpak run info.cemu.Cemu -g {rom}
Switch: flatpak run org.yuzu_emu.yuzu -g {rom}
PlayStation 1: flatpak run org.duckstation.DuckStation {rom}
PlayStation 2: flatpak run net.pcsx2.PCSX2 {rom}
PlayStation 3: flatpak run net.rpcs3.RPCS3 {rom}
Native Binaries, RetroArch & Windows:
RetroArch (Core): retroarch -L /path/to/core_libretro.so {rom}
AppImage / Binary: /home/user/Applications/emulator.AppImage {rom}
Windows (.exe): "C:\Emulators\Dolphin\Dolphin.exe" -b -e {rom}
Display Variables: env DISPLAY=:0 WAYLAND_DISPLAY=wayland-0 flatpak run ... {rom}
