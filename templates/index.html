Manual Cover Art Placement Guide
Folder Location for Custom Box Art:

Place your image files directly into the static/covers/ directory in your ROMcat installation folder.

Cover Image Naming Formula:
Format: <system_id>_<rom_filename_without_extension>.jpg

Spaces, parentheses, brackets, dots, and special characters in the ROM filename are replaced with underscores (_).

Naming Examples:
NES:
ROM: Super Mario Bros (USA).nes
→ Cover: nes_Super_Mario_Bros__USA_.jpg
SNES:
ROM: Chrono Trigger [!].sfc
→ Cover: snes_Chrono_Trigger____.jpg
Nintendo 64:
ROM: The Legend of Zelda - Ocarina of Time (USA).z64
→ Cover: n64_The_Legend_of_Zelda_-_Ocarina_of_Time__USA_.jpg
GameCube:
ROM: Super Smash Bros Melee.iso
→ Cover: gamecube_Super_Smash_Bros_Melee.jpg
Switch:
ROM: Super Mario Odyssey.nsp
→ Cover: Switch_Super_Mario_Odyssey.jpg
Image Specifications & Tips:
  • Supported Formats: .jpg, .jpeg, .png, .webp
  • Recommended Aspect Ratio: Standard vertical box art ratio 3:4 (e.g. 300 × 400 or 600 × 800 pixels).
  • Instant Refresh: After copying images to static/covers/, click Rescan below to instantly update the catalog.
  • In-Catalog Search: You can also click the Find cover input on any game card missing art to search SteamGridDB with custom search keywords directly.

Consoles & Commands Configuration Guide
System Identifier (ID) — When is it needed?

You can leave this box empty. When you fill in the Display Name (such as Nintendo 64), ROMcat automatically creates a safe internal ID for you behind the scenes.

Only type in this box if:

  • Your Display Name contains special characters, slashes, or symbols (e.g. Game Boy / Color or PC Engine & TG-16) and you want a clean internal key like gbc or pce.
  • You specifically want a custom short nickname (like n64 instead of nintendo64).

The Emulator Launch Command is the exact shell command used to start the emulator with your selected game.

Key Token: {rom}

ROMcat automatically replaces {rom} with the full, shell-quoted path to the selected ROM file on disk (e.g. "/home/user/ROMs/NES/Mario.nes").

Common Flatpak Emulator Commands:
NES: flatpak run ca._0ldsk00l.Nestopia {rom}
SNES: flatpak run com.snes9x.Snes9x {rom}
Nintendo 64: flatpak run io.github.gopher64.gopher64 {rom}
GameCube / Wii: flatpak run org.DolphinEmu.dolphin-emu {rom}
Wii U: flatpak run info.cemu.Cemu -g {rom}
Switch: flatpak run org.yuzu_emu.yuzu -g {rom}
PlayStation 1: flatpak run org.duckstation.DuckStation {rom}
PlayStation 2: flatpak run net.pcsx2.PCSX2 {rom}
PlayStation 3: flatpak run net.rpcs3.RPCS3 {rom}
Native Binaries, RetroArch & Windows:
RetroArch (Core): retroarch -L /path/to/core_libretro.so {rom}
AppImage / Binary: /home/user/Applications/emulator.AppImage {rom}
Windows (.exe): "C:\Emulators\Dolphin\Dolphin.exe" -b -e {rom}
Display Variables: env DISPLAY=:0 WAYLAND_DISPLAY=wayland-0 flatpak run ... {rom}
